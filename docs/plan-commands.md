# План: новый набор команд и экономика «алмазов»

Резюме решений, согласованных с пользователем. Документ фиксирует дизайн до начала кода.

## 1. Общий подход к командам
- Видимый список команд (меню бота `setMyCommands` + раздел в `/help`) заменяется на **12 новых команд** ниже.
- Внутренние команды управления игрой **остаются работать**, но скрыты из меню и `/help`:
  `/pause`, `/resume`, `/kick`, `/transfer`, `/settings`, `/players`, `/adminlog`,
  `/nextphase`, `/rules`, `/mafia`, `/report`, `/privacy`, `/deleteme`, `/profile`, `/shop`.
  → скрытые команды знает ведущий, их можно вводить вручную.

### Публичный список (12)
| Команда | Действие |
|---|---|
| `/game` | Открыть новый набор (создать игру/лобби). Проверяет активную аренду группы. |
| `/extend` | Продлить регистрацию (набор открыт дольше). |
| `/start` | Завершить регистрацию и начать игру (= старый `/begin`). |
| `/stop` | Отменить набор/игру (= старый `/stopgame`). |
| `/leave` | Выйти из набора/игры. |
| `/next` | Анонс «следующая игра скоро» (напоминание в группе). |
| `/top` | Рейтинг игроков (есть). |
| `/balance` | Баланс алмазов (свои алмазы; в группе ещё пул чата и статус аренды). |
| `/prolong` | Продлить аренду бота в группе (10 алмазов / месяц). |
| `/give` | Передать алмазы в общий пул чата. |
| `/share` | Пригласить друзей (личная реферальная ссылка + награда). |
| `/help` | Помощь со списком команд. |

## 2. Экономика: 3 независимые валюты
- 💵 **деньги** и 💎 **камни** — внутриигровые (магазин/профиль), **без изменений**.
- 🔷 **алмазы** — новая премиум-валюта:
  - зарабатываются через приглашения `/share` и выдаются владельцем (административно, через БД);
  - тратятся на **аренду бота** в группах;
  - переводятся в **общий пул чата** через `/give`.

## 3. Получение алмазов: `/share` (реферал)
- `/share` в личном чате показывает уникальную ссылку вида
  `https://t.me/<bot>?start=invite_<tg_id>` + подсказку.
- Когда по такой ссылке **впервые** стартует новый игрок (создаётся профиль):
  - пригласивший получает **+2 🔷**;
  - новичок получает **+1 🔷**;
  - закрепляется `invited_by` у новичка (награда выдаётся один раз).
- Отслеживание: новые колонки в профиле/экономике пользователя.

## 4. Пул чата: `/give`
- В каждой группе есть общий пул алмазов и срок аренды (`rental_until`).
- `/give <число>` в группе: снимает алмазы с баланса игрока и кладёт их в **пул группы**.
  - минимум 1; нельзя дать больше, чем есть; сообщение-подтверждение.
- Пул тратится на аренду бота (`/prolong`).

## 5. Аренда бота: `/prolong` (монетизация владельцу)
- Работа бота в группе требует **активной аренды**: `rental_until` > сейчас.
- `/prolong` (только в группе, от участника/админа):
  - цена **10 🔷 / 30 дней**;
  - если в пуле чата < 10 🔷 → отказ с подсказкой `/give`;
  - иначе −10 🔷 из пула, `rental_until += 30 дней`, **+10 🔷 владельцу** бота
    (аккаунт `OWNER_TELEGRAM_ID`, виден ему через `/balance`).
- Группы без активной аренды: `/game` отвечает, что аренда истекла и как её продлить.
- Новые группы получают небольшой **пробный период** (напр. 24 ч), чтобы можно было проверить.

## 6. `/next`, `/extend`
- `/next` (в группе): короткий анонс «🗓 Следующая игра скоро — подпишитесь/готовьтесь», при желании призывает открыть набор командой `/game`.
- `/extend` (в группе, ведущий): регистрация в модели бота открыта, пока не нажат `/start`;
  поэтому команда показывает статус набора и, если набор активен, подтверждает, что он продолжает принимать игроков (без таймера продлевать нечего). При наличии таймера набора — продлевает его.

## 7. Изменения в коде
- **БД** (`src/database.ts`, миграция):
  - колонка `diamonds INTEGER DEFAULT 0` в экономике пользователя;
  - колонки `invited_by`, `invite_rewarded` для рефералов;
  - таблица `chat_diamonds (chat_id PK, diamonds INT, rental_until TIMESTAMPTZ)`.
  - функции: кредит/списание алмазов, пополнение пула, проверка/продление аренды,
    обработка реферала (атомарно, без двойной выдачи), показать баланс.
- **Текст** (`src/text.ts`): тексты для баланса, аренды, пула, share, next, команд `/help`.
- **Стартовый обработчик** (`src/index.ts`):
  - `/start` разбирает payload: `invite_<id>` (реферал) / `join_<id>` (вступление в набор) /
    без payload в группе → начать игру, в личке → приветствие.
  - реестр команд и `/help` = только 12 публичных.
- **Игровой движок** (`src/game-engine.ts`): методы `/extend`, `/next`, проверка аренды
  при `/game`, оставить внутренние команды рабочими.

## 8. Примечания по рискам
- Реальных денежных платежей в коде нет: алмазы зарабатываются приглашениями и выдаются
  владельцем вручную. Привязка «10 🔷 ≈ 300 ₽» — маркетинговая, без платёжного провайдера.
- `stop`/`start` как имена: `/start` уже используется для deep-link, поэтому логика объединяется
  в общем обработчике; конфликтов не ожидается.
- Если аренда в группе истекла во время **активной игры** — текущую игру не обрываем,
  ограничение действует только на открытие новых наборов.

## 9. Что НЕ делаем в этой итерации
- Платёжный провайдер / покупка алмазов за реальные деньги (только `/share` + ручная выдача).
- Внутренние команды управления не показываем в меню, но и не удаляем.
